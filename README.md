# Gatherly – Event Management Website

A responsive event management website built for **K Explore – Web Designing**.

## Features
- Hero section with live countdown to the next event
- Event cards (name, date, venue, image, short description)
- Search and category filters
- Event details popup with a register button
- Registration form with JavaScript validation and a confirmation message
- Dark / light mode, animations, and Local Storage for registrations (bonus)
- Fully responsive: mobile, tablet and desktop

## Tech Stack
HTML5, CSS3, JavaScript (no frameworks). Git and GitHub for version control.

## Run Locally
Open `index.html` in a browser.

## Project Structure
```
index.html   structure
style.css    styling and responsive layout
script.js    events data, filters, modal, countdown, validation, Local Storage
```
